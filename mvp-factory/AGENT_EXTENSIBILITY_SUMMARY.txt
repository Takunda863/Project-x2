QUESTION 2: Can I swap/remove/replace models?
✅ YES - COMPLETE FLEXIBILITY

Current Model Support:
┌─ OpenAI Provider
│  ├── gpt-3.5-turbo (fast, cheap)
│  ├── gpt-4o-mini (balanced, DEFAULT)
│  ├── gpt-4-turbo (powerful)
│  └── gpt-4 (best quality)
│
└─ Hugging Face Provider
   ├── meta-llama/Llama-2-7b
   ├── meta-llama/Llama-2-13b
   ├── meta-llama/Llama-2-70b
   ├── mistralai/Mistral-7B
   └── [ANY HUGGING FACE MODEL]

Methods to Change Models:
1. Environment Variables (easiest)
   export OPENAI_DEFAULT_MODEL="gpt-4-turbo"
   export LLM_PROVIDER="hf"
   export HF_MODEL_PATH="meta-llama/Llama-2-70b"

2. Runtime Options (most flexible)
   opts=LLMCallOptions(model="gpt-4-turbo", temperature=0.2)

3. Per-Agent Configuration
   class MyAgent(BaseAgent):
       async def perform(...):
           await call_llm(..., opts=LLMCallOptions(model="gpt-4"))

4. Add New Provider
   Extend BaseProvider, update get_provider() function

Cost Control:
├── Testing: gpt-3.5-turbo (cheapest)
├── Default: gpt-4o-mini (balanced)
├── Production: gpt-4-turbo (powerful)
└── Complex Tasks: gpt-4 (best)

QUESTION 3: Are models in sandboxes?
✅ YES - MODELS ARE SANDBOXED

Execution Flow:
Your Code (SANDBOXED Dev Container)
    ↓
llms/manager.py (LOCAL, SANDBOXED)
    ↓
External API Call (OpenAI/Hugging Face - EXTERNAL)
    ↓
LLM Model (REMOTE, NOT in sandbox)
    ↓
Response Returned (to your sandboxed code)

Safety Guarantees:
✅ No model storage locally
✅ No credentials in code (env vars only)
✅ No local model execution
✅ No file access from models
✅ Unidirectional data flow (code → API → response)
✅ Dev container isolation
✅ Process isolation
✅ Network controlled access

Architecture Isolation:
┌─────────────────────────────────────────────────────────┐
│                  SANDBOX (Dev Container)                 │
│  ┌────────────────────────────────────────────────────┐  │
│  │  Your Code                                         │  │
│  │  agents/                                           │  │
│  │  llms/manager.py (makes API calls)                │  │
│  │  All processing local                             │  │
│  └────────────────────────────────────────────────────┘  │
│                                                           │
│        ↓ (API Call over HTTPS)                           │
│        ┌────────────────────────────────────┐            │
│        │ EXTERNAL API (NOT in sandbox)     │            │
│        │ - OpenAI API                       │            │
│        │ - Hugging Face API                 │            │
│        │ - Model execution (remote)         │            │
│        └────────────────────────────────────┘            │
└─────────────────────────────────────────────────────────┘

If You Want Local Models (Optional):
├── Small models can run in sandbox (4GB+ RAM needed)
│   export LLM_PROVIDER="hf"
│   export HF_MODEL_PATH="microsoft/phi-2"
│
├── Quantized models (CPU-friendly)
│   Use GGML format with ollama
│
└── Still sandboxed - models loaded locally but code isolated
